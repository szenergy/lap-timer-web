# SZEnergy Lap Timer

A simple lap timer for Shell Eco‑marathon, by SZEnergy. It tracks laps, compares them against an optimal target time, and can export results to CSV.

## Features
- Start/stop timing with live feedback
- Lap list with per‑lap diffs
- Optional energy input per lap
- CSV export

## Usage
You have two options:
1. Clone the repository and open `index.html` in a browser.
2. Use the hosted version at [szenergy.github.io](https://szenergy.github.io/lap-timer-web/).

### Controls
- **Start** button or `spacebar`: begin timing
- **Lap** button or `spacebar`: record a lap
- **Stop** button: end the final lap

### CSV Export
Click **Download CSV** to save the lap data in a spreadsheet‑friendly format.
